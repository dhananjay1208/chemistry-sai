# Chemistry with Sai — NEET Interactive Prep

An interactive Chemistry learning app built for Sai's NEET 2026 preparation.
Each topic is taught through **concepts + visuals + games + MCQs + NEET PYQs + numericals**.

## Chapter 1 — Redox Reactions

- **Oxidation Number** — 8 golden rules, LEO-GER analogy, Oxidation Detective game
- **Stock Notation** — Roman numerals, side-by-side O.N. compare, naming game
- **Balancing Redox** — half-reaction method, step-by-step balancer, "Balance the Equation" puzzle
- **Equivalent Mass** — n-factor rules, titration calculator, rapid-fire quiz

Every topic includes:
- Concept tab with analogies & common mistakes
- Visualize tab with animated walkthroughs
- Game tab for active recall
- 10–20 concept-check MCQs with explanations
- NEET previous-year questions (2014–2022)
- Step-by-step worked numericals

## Tech

- Vite + React 18
- TailwindCSS
- Framer Motion (animations)
- React Router (hash-based for simple static hosting)
- Lucide icons
- Progress saved in localStorage

## Local dev

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Deploy to Netlify

The `netlify.toml` is preconfigured. Push this repo to GitHub and connect it in Netlify —
the build command and publish directory are already set.
